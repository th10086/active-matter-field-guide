# Active Matter Domain Recommendation

Checked: 2026-09-16 (Asia/Shanghai)

## Recommendation

**First choice: `activematterfieldguide.com`**

Why it fits:

- Contains the game name for clear discovery.
- `fieldguide` signals an independent reference site rather than an official publisher property.
- Broad enough for raids, maps, enemies, systems and updates.
- No hyphen and no plural ambiguity.

## Backup choices

|---:|---|---|---|
| 1 | `activematterfieldguide.com` | Best balance of clarity, trust and expansion room | Longer than a short brand domain |
| 2 | `amfieldguide.com` | Short and memorable | Less obvious search relevance for new visitors |
| 3 | `activematterguides.com` | Clear guide intent and good category fit | More generic and plural |
| 4 | `active-matter-guide.com` | Immediately understandable | Hyphenated and less convenient to say/type |
| 5 | `active-matter-fan-guide.com` | Explicitly unofficial | Too long for normal sharing |

## Names to avoid

- `activematterwiki.com`: “wiki” suggests a canonical database, and several similarly named sites already compete for that identity.
- `activematterhq.com`: “HQ” can imply an official headquarters.
- Any domain containing `official`, `gaijin`, `matterteam`, `steam`, `download`, `key`, `cheat` or `torrent`.

The game name is associated with Gaijin/Matter Team branding, so the site should keep the unofficial disclaimer visible and avoid language that suggests publisher ownership. The [USPTO TSDR service](https://tsdr.uspto.gov/) is the correct place to verify trademark status before using the name commercially.

## Availability note

Verisign `.com` RDAP returned no registered-domain record for all five preferred candidates on the check date. This is only a preliminary availability signal. A registrar checkout can still reject a name because of a recent reservation, premium pricing, registry hold or a concurrent purchase.

Before buying:

1. Check the exact spelling at the registrar.
2. Confirm the renewal price, not only the first-year price.
3. Enable domain privacy and two-factor authentication.
4. Buy the `.com` first; add a second extension only if it protects a real traffic source.

The project keeps `siteUrl` on a reserved placeholder until the user supplies the purchased domain. Do not deploy or change canonical URLs before that point.
