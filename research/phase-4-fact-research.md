Search order is volatile and location-dependent. These are the first two relevant English results observed during the 2026-09-16 research session; they are reference competitors, not fact authorities.

| Query | Result 1 | Result 2 | Coverage and useful structure | Reliability finding |
|---|---|---|---|---|

| `Active Matter guide` | activematterwiki.wiki Guides | active-matter.wiki Guides Hub | Beginner flow, extraction, loadouts, maps, systems | Both contain unsupported tactical claims; re-source every field |
| `Active Matter wiki` | wiki.gg | activematterwiki.wiki | Entity pages vs SEO topic clusters | wiki.gg has edit provenance but still community-authored; the SEO wiki contains multiple likely fabricated specifics |
| `Active Matter codes` | No credible game result | Irrelevant software/science results | No verified redeem-code intent | Do not create a Codes page in the first release |
| `Active Matter tier list` | active-matter.wiki Weapons Hub | activematter.blog tier list | Class rankings, role, ammo and handling criteria | Rankings conflict across sites and include unsupported stats; only use as keyword/structure research |
| `Active Matter beginner guide` | GameBrief beginner guide | activematterwiki.wiki beginner guide | Editions, first raid, zones, loadouts | GameBrief mostly summarizes official mechanics; the second result contains unverified markers, distances, enemies and timers |
| `Active Matter maps` | active-matter.wiki Maps Hub | activematterwiki.wiki unlock-maps guide | Location index and supposed unlock sequence | The unlock guide asserts precise recipes and steps not found in official sources; exclude them |
| `Active Matter update` | activematterwiki.wiki Updates | SteamDB current patch mirror | Patch summaries and impact | Use official patch notes or SteamDB mirrors, not the community summary as primary evidence |

### Reusable competitor fields

- Page taxonomy: beginner, raid modes, maps, weapons, enemies/anomalies, Workshop, Monolith/Harmonization, editions, system requirements, patches.
- Useful presentation fields: patch/version, last verified date, source class, location/role, mode, risk level and prerequisites.
- Useful user questions: how to extract, how Isolated differs from Open, how to prepare a loadout, where systems moved after patches, what carries through Harmonization.

### Fields requiring independent verification

- Damage, armor penetration, recoil, DPS, TTK and effective range.
- Spawn radius, aggression radius, boss timer and encounter composition.
- Loot chance, drop table, extraction time and map rotation timing.
- Exact map unlock steps and recipe quantities.
- Any S/A/B/C ranking presented as objective fact.
- Cross-platform party, loot-share and revive claims not stated in current official documentation.

## 10. Phase 4 readiness decision

- Enough verified material exists for a strong homepage, official facts, platforms, editions, locations overview, modes overview, Flowermen page and patch/update hub.
- Enough official naming exists to plan a broader page matrix, but many detailed guide pages still need launch-build gameplay evidence.
- Do not commit to a 35-page first release from the current fact set alone.
- Phase 5 must prioritize pages supported by official sources and treat community queries as demand signals, not evidence.
