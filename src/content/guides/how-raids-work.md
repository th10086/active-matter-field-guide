## The extraction loop

The official description is intentionally simple: enter a quantum-unstable zone, gather Active Matter and loot, and extract before the zone ceases to exist. That loop is the reliable baseline for every beginner explanation on this site.

## What changes from raid to raid

The selected mode, location, squad choice and current patch can all change the risk profile. Keep those variables visible when comparing community advice. A route, timer or drop table without a version and source is not treated as a fixed rule here.

## Extraction is the objective

The run is not complete when you find an item. It is complete when you return with it. Use the official mode descriptions and current client to decide how much risk to accept; this page does not invent coordinates or extraction timers.
