## Short answer

Yes. The current official FAQ lists dedicated PvE alongside extraction raids and dedicated PvP. That means Active Matter should not be described as PvPvE-only.

## PvE versus PvP

PvE is the lower-competition choice when you want to learn locations and systems. Dedicated PvP is a separate activity. Open and Isolated raid rules are explained on the raid-modes page because they are a different question from whether PvE exists.

## About the “PvE limit” question

Search demand asks whether PvE still has a limit. The current source set confirms availability, but not a universal limit value. Check the current client and official patch notes before publishing a numeric answer.
